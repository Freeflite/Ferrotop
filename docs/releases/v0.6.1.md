Ferrotop can now open in place of Task Manager.

## What's new

- **Open Ferrotop instead of Task Manager** (View menu, with administrator approval). The
  taskbar's Task Manager, Ctrl+Shift+Esc and the Ctrl+Alt+Del screen open Ferrotop instead, as
  Process Explorer and System Informer can. Untick it to put Task Manager back.
  - It opens Ferrotop's copy in Program Files, which only administrators can change, never the
    copy you downloaded. That's the same copy the history service runs from, so ticking the box
    updates the service too.
  - Started in Task Manager's place, Ferrotop ignores the arguments Task Manager was given, so
    nothing can use that launch to trigger its administrator actions.
  - Unticking it removes only Ferrotop's own setting; another program's Task Manager replacement
    is left alone. Stopping the history service keeps the Program Files copy while Task Manager
    still opens it.

## Fixes

- Launching Ferrotop while it's already running (a click, or Ctrl+Shift+Esc) now brings its
  window to the front. Before, the window could stay behind others.

## Download

- **`ferrotop.exe`**: the whole program in one file. No installer, no runtime to install; run it
  from anywhere. Run it as administrator (or click **Run as administrator** in its status bar)
  to see every process's details.
- **`ferrotop-0.6.1-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows
"Windows protected your PC". Choose **More info → Run anyway**. If you'd rather check what
you're running first, see below, or build it yourself from the source with
`pwsh scripts/build-release.ps1`: the build is reproducible.

If the history service is installed, the History page offers **Update service…** so it runs
this version too.

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotop.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI
  from the tagged commit. With the GitHub CLI:
  `gh attestation verify ferrotop.exe --repo Freeflite/Ferrotop`
