A small fix to Ferrotop 0.5.0.

## What's fixed

- **CCD boxes show without administrator rights.** In Performance → CPU → CCX, the CCXs of each
  CCD were boxed together only when Ferrotop could read the CPU temperature sensors, which takes
  the PawnIO driver and running as administrator. Run normally, you got loose CCXs. On the
  multi-CCD chips of AMD's Zen, Zen+ and Zen 2 generations (Ryzen 9 3000, Threadripper
  1000–3000, EPYC 7001 and 7002), Ferrotop now reads each CCX's CCD from the CPU itself, so the
  boxes show either way, and each CCD's temperature joins its box when the sensors can be read.
  Other CPUs work as before; from Zen 3 on, a CCD is usually a single CCX, so there's nothing to
  box.
- The About box takes its version number from the build instead of a hard-coded one.

## Download

- **`ferrotop.exe`**: the whole program in one file. No installer, no runtime to install; run it
  from anywhere. Run it as administrator (or click **Run as administrator** in its status bar)
  to see every process's details.
- **`ferrotop-0.5.1-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows
"Windows protected your PC". Choose **More info → Run anyway**. If you'd rather check what
you're running first, see below, or build it yourself from the source with
`pwsh scripts/build-release.ps1`: the build is reproducible.

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotop.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI
  from the tagged commit. With the GitHub CLI:
  `gh attestation verify ferrotop.exe --repo Freeflite/Ferrotop`
