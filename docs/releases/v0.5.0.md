The first public release of Ferrotop, a memory-safe process explorer for Windows written in
Rust: a re-imagining of System Informer with a Slint UI.

## Download

- **`ferrotop.exe`**: the whole program in one file. No installer, no runtime to install; run it
  from anywhere. Run it as administrator (or click **Run as administrator** in its status bar)
  to see every process's details.
- **`ferrotop-0.5.0-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows
"Windows protected your PC". Choose **More info → Run anyway**. If you'd rather check what
you're running first, see below, or build it yourself from the source with
`pwsh scripts/build-release.ps1`: the build is reproducible.

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotop.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI
  from the tagged commit. With the GitHub CLI:
  `gh attestation verify ferrotop.exe --repo Freeflite/Ferrotop`

## What's in it

- **Processes:** a live tree with icons, cycle-based CPU, GPU, I/O and memory columns, verified
  signers, and a right-click menu: properties, open file location, end process (or tree),
  suspend and resume, priority, affinity, and dump file.
- **Process properties:** general, threads (live CPU and call stacks), modules, memory regions,
  handles, environment, token and services.
- **Performance:** CPU overall, per core, per thread or per CCX (grouped by CCD), memory, disks,
  network and GPUs. CPU temperatures come from the [PawnIO](https://pawnio.eu) driver if you've
  installed it (run as administrator), or from LibreHardwareMonitor's local web server. Hide
  any graph from the View menu.
- **Services** (start, stop, restart), **network connections**, **find handles or DLLs**, and
  **run** a new program.

See the [README](https://github.com/Freeflite/Ferrotop#readme) for details and
[SECURITY.md](https://github.com/Freeflite/Ferrotop/blob/main/SECURITY.md) for how Ferrotop is
hardened and how to report a problem.
