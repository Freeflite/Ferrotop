Ferrotop can now install itself, and start as administrator without a prompt.

## What's new

- **A Settings pane** (View → Settings…) holds the theme, the tray, starting at sign-in, the
  header graphs, and installing. The View menu keeps the options for the page you're on.
- **Install from the exe itself.** Settings → Install (with administrator approval) puts
  Ferrotop in Program Files, adds it to the Start menu, and lists it in Settings → Apps.
  - Run a newer download and Settings offers to update the installed copy to it.
  - Uninstall… in Settings, or removing it from Settings → Apps, takes out everything installing
    and the other options set up: the copy, the shortcut, the history service, Task Manager's
    replacement and the administrator start. Your settings and recorded history are kept.
  - The installed copy is the same protected one the history service and Task Manager's
    replacement already used, so installing also updates a running history service.
- **Always run as administrator, without a prompt** (Settings, once installed; it asks once,
  when you turn it on). Ferrotop then opens with administrator rights from the Start menu, at
  sign-in (still in the tray) and with Ctrl+Shift+Esc, with no UAC prompt.
  - It works through a scheduled task for your account, the only way Windows skips the prompt.
    The task starts only the installed copy in Program Files, which only administrators can
    change, with a fixed command line, so nothing else can use it to run as administrator.
  - A Ferrotop started from anywhere else hands over to it only if it's the very same build.
  - If you had ticked "Run this program as an administrator" in the installed copy's Properties,
    turning this on clears it: that setting stops Task Manager's replacement from opening.
- **Start at sign-in** now starts the installed copy when there is one, rather than a download
  that may move.

## Download

- **`ferrotop.exe`**: the whole program in one file. Run it from anywhere, or install it from
  View → Settings… → Install.
- **`ferrotop-0.7.0-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows
"Windows protected your PC". Choose **More info → Run anyway**. If you'd rather check what
you're running first, see below, or build it yourself from the source with
`pwsh scripts/build-release.ps1`: the build is reproducible.

Already installed, or using the history service or Task Manager's replacement? Open Settings in
this version and choose **Update to this version** (or **Install**, if you set those up before
installing existed).

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotop.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI
  from the tagged commit. With the GitHub CLI:
  `gh attestation verify ferrotop.exe --repo Freeflite/Ferrotop`

See the [README](https://github.com/Freeflite/Ferrotop#readme) for everything Ferrotop does and
[SECURITY.md](https://github.com/Freeflite/Ferrotop/blob/main/SECURITY.md) for how it's hardened
(including what the administrator start allows and doesn't) and how to report a problem.
