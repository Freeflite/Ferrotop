Ferrotop 0.6 can keep a history of the whole machine, even with its window closed, and lets you
arrange it however you like. It also adds per-process disk and network activity, a window list,
ping and trace route, and a tray icon.

## What's new

- **History, around the clock.** An optional history service (installed from the History page,
  with administrator approval) records every figure the Performance page shows: each core and
  CCD with its temperature, each disk and network adapter, and GPU load, engines, memory,
  temperature, hotspot, power, fan and clocks. It keeps a week: every second for the overall
  figures, and each minute's average and peak for the rest after the first day. It also records
  the busiest programs of every minute.
- **A History page that's yours to arrange.** Graph the last hour, day or week.
  - **Choose graphs:** add them with **Add graphs…**, or right-click anything on the Performance
    page (a graph, a core or CCX, a CCD's box, a device, a figure) and choose **Show in History**.
  - **Arrange them:** drag a graph by its title to move it, or drag its right or bottom edge to
    resize it; widths snap to twelfths of the page.
  - **Layouts:** **Layouts** has ready-made arrangements (Overview, Temperatures, GPU, CPU,
    Compact). It also lists any layout files in `%APPDATA%\Ferrotop\Layouts`, and saves the
    current layout there as JSON to edit or share.
  - **Programs:** the table of the busiest programs can be hidden, and the bar beside it drags
    to share the room.
- **Header graphs of your choice.** The small graphs beside the tabs can show any figure, such
  as CPU temperature, GPU load or VRAM. Choose them by right-clicking one, from View → Header
  graphs…, or with **Show in the header** on the Performance page. Drag one sideways to reorder
  them.
- **Graphs aren't empty at startup.** With the service running, the CPU and memory graphs open
  with the last minute already drawn.
- **Per-process disk and network activity.** Disk and Network columns, from a kernel event
  trace like Resource Monitor's. They need Ferrotop to run as administrator, or the history
  service, which also shares CPU temperatures with Ferrotop windows that aren't elevated.
- **Windows.** A Windows page lists every window on the desktop and the process it belongs to,
  and each process's properties have a Windows tab. **Pick a window** jumps to the process of
  whichever window you click.
- **Ping and trace route**, from View → Ping… or a connection's actions. Only the address you
  give is contacted: there's no whois or geolocation lookup.
- **Tray icon.** Closing the window can leave Ferrotop running in the tray. View → Start at
  sign-in starts it there when you sign in, and launching it again shows the copy that's already
  running.
- **Columns you can move and resize, in every table.** Drag a heading to move a column, or its
  edge to resize it; the layout is saved per table. The process list gains a **RAM** column (the
  private working set, Task Manager's "Memory").

## Fixes

- The window could open short, with the page squeezed into its top part until you visited
  History.
- Parts of the window could stay blank or see-through after it was maximized, most often a
  strip at the top right.
- In dark mode, the title bar could start out light until you switched themes.

## The history service

It runs as LocalSystem, so it's built to take nothing from ordinary users. It reads no requests.
It runs from its own copy in Program Files, keeps only the three privileges it needs, and writes
only to `%ProgramData%\Ferrotop`, a folder only administrators can change. **Stop recording**
removes it and keeps what was recorded. See
[SECURITY.md](https://github.com/Freeflite/Ferrotop/blob/main/SECURITY.md) for the details.

If you installed the service from a build of 0.6 before this release, the History page offers
**Update service…** so it records everything this one can.

## Download

- **`ferrotop.exe`**: the whole program in one file. No installer, no runtime to install; run it
  from anywhere. Run it as administrator (or click **Run as administrator** in its status bar)
  to see every process's details.
- **`ferrotop-0.6.0-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows
"Windows protected your PC". Choose **More info → Run anyway**. If you'd rather check what
you're running first, see below, or build it yourself from the source with
`pwsh scripts/build-release.ps1`: the build is reproducible.

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotop.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI
  from the tagged commit. With the GitHub CLI:
  `gh attestation verify ferrotop.exe --repo Freeflite/Ferrotop`

See the [README](https://github.com/Freeflite/Ferrotop#readme) for everything Ferrotop does and
[SECURITY.md](https://github.com/Freeflite/Ferrotop/blob/main/SECURITY.md) for how it's hardened
and how to report a problem.
