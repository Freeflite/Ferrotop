Ferrotop now shows each thing as soon as it can read it, instead of waiting for everything.

## What's changed

- **No more blank start.** Ferrotop used to read the CPU, memory, GPUs, Windows' performance
  counters and every disk one after another, and show nothing (not even the process list) until
  all of them had answered. One slow source, such as a USB drive spinning up, could leave the
  window empty for several seconds.

  Now the process list, CPU and memory come from one thread and show at once. The Performance
  view's devices come from another, which adds each as it becomes ready: network adapters
  straight away, disks and GPU use once the performance counters are loaded, and GPU hotspot,
  fan and power once the AMD or NVIDIA driver library is. Each disk is read on its own thread, so
  a drive that's spinning up holds up only itself.
- **Your device choice survives startup.** If you left a disk or the GPU selected, the CPU shows
  until that device appears, then it switches back.
- The check for LibreHardwareMonitor, which takes a moment when it isn't running, now waits until
  everything else is set up.

## Download

- **`ferrotop.exe`**: the whole program in one file. No installer, no runtime to install; run it
  from anywhere. Run it as administrator (or click **Run as administrator** in its status bar)
  to see every process's details.
- **`ferrotop-0.5.2-windows-x64.zip`**: the same exe with its license notices.

Needs 64-bit Windows 10 or 11.

**Windows will warn you the first time.** The exe isn't code-signed, so SmartScreen shows
"Windows protected your PC". Choose **More info → Run anyway**. If you'd rather check what
you're running first, see below, or build it yourself from the source with
`pwsh scripts/build-release.ps1`: the build is reproducible.

## Verify your download

- **Checksum:** compare `Get-FileHash ferrotop.exe` with the matching line in `SHA256SUMS.txt`.
- **Provenance:** GitHub signed an attestation that this exe was built by this repository's CI
  from the tagged commit. With the GitHub CLI:
  `gh attestation verify ferrotop.exe --repo Freeflite/Ferrotop`
